lavaan — Structural Equation Modeling

                        

                          

                            
Full SEM with latent variables requires the lavaan package.

                            
# Example lavaan syntax:
model <- "
  # Measurement model (latent variables)
  ability =~ x1 + x2 + x3
  speed   =~ x4 + x5

  # Structural model (regressions)
  speed ~ ability
  outcome ~ speed + ability
"
fit <- lavaan::sem(model, data = your_data)
summary(fit, fit.measures = TRUE, standardized = TRUE)

                            

                            
Install and use in your R console for now. Full UI integration coming soon.

                            install.packages('lavaan')
                          

                        

                        
                      

                    

                  

                  

                    

                      

                        
Moderation Analysis (Interaction)

                        

                          

                            
Moderation is tested by including an interaction term in regression.

                            
# Moderation: does Z moderate the X -> Y effect?
fit <- lm(Y ~ X * Z, data = df)   # X:Z = interaction
summary(fit)
# If X:Z coefficient is significant -> moderation confirmed

                            

                            
Use the Regression screen with an interaction term (X*Z) as a predictor.

                            
Full moderation diagnostics panel coming in next build.

What is a Bayes Factor (BF)?

                            
BF₁₀ = P(data | H₁) / P(data | H₀). Ratio of evidence for H₁ vs H₀.

                            

                              
                                

                                  BF₁₀
                                  Evidence
                                

                              
                              
                                

                                  1–3
                                  Anecdotal for H₁
                                

                                

                                  3–10
                                  Moderate for H₁
                                

                                

                                  10–30
                                  Strong for H₁
                                

                                

                                  30–100
                                  Very strong for H₁
                                

                                

                                  > 100
                                  Decisive for H₁
                                

                                

                                  < 1
                                  Evidence for H₀

Documentation

                

                  A guide to running analyses in EasyAnalysis — no code required. Use the contents
                  list on the right to jump to a section.
                

                

                

                  
1. What EasyAnalysis is

                  

                    EasyAnalysis is a platform for running 
                    
                      basic-to-intermediate statistical, 
                      machine-learning and spatial analysis by clicking, not coding
                    
                    . Upload your data, pick
                    what you want, and read the results in plain English.
                  

                  

                    It runs 
                    entirely in your browser
                     (compiled to WebAssembly). 
                    Your data never leaves your computer
                     — nothing is uploaded to a server. The first
                    visit takes about 3–5 minutes to download the R environment into your browser; after that it
                    loads instantly from cache.
                  

                

                

                  
2. The interface

                  
    
                    
  • 
                      Top menu bar
                       — analysis categories (Data, Statistical Models, Machine
                      Learning, Spatial & LiDAR, and more), plus R Console, Documentation and References.
                    
    • 
                    
  • 
                      Left data rail
                       — 
                      Add Data
                       and 
                      New Dataset
                       buttons, your loaded datasets (click one to make it active), and 
                      View Data
                      .
                    
    • 
                    
  • 
                      Center canvas
                       — the active screen (results, plots, maps).
                    
    • 
                    
  • 
                      Right tools panel
                       — the controls for the active screen.
                    
    • 
                    
  • 
                      Status bar
                       — the active dataset and its dimensions.
                    
    • 
                    
  • 
                      Settings (gear, top-right)
                       — your OpenAI key, About and Acknowledgements.
                    
    • 
                  

                

                

                  
3. Loading your data

                  
    
                    
  • 
                      Add Data
                       — upload 
                      CSV, Excel (.xlsx), text
                      , or spatial
                      files: 
                      GeoTIFF (.tif), LAS/LAZ point clouds, GeoJSON, GeoPackage, Shapefile
                       (select all shapefile parts together).
                    
    • 
                    
  • 
                      New Dataset
                       — build one from scratch in a spreadsheet grid, or paste
                      straight from Excel.
                    
    • 
                    
  • 
                      Make a dataset active
                       — click it in the left rail. Every analysis uses the
                      active dataset automatically (there is no per-screen dataset picker).
                    
    • 
                    
  • 
                      View Data
                       — inspect and edit cells; 
                      ×
                       removes a dataset.
                    
    • 
                  

                

                

                  
4. Exploring & preparing data

                  

                    Data & Exploration
                     is your ETL and EDA workbench: clean columns, transform
                    variables (log / sqrt with bias-corrected back-transform), filter rows, aggregate, rename or
                    merge levels, and handle missing values — with 
                    Undo
                     and 
                    Reset to Upload
                     at any time. It also draws quick exploratory plots.
                  

                  

                    Recommend
                     gives a plain-English read on what your data looks like and which
                    methods suit it, before you model.
                  

                

                

                  
5. Running an analysis

                  
    
                    
  1. Open the screen you want from the top menu.
    2. 
                    
  2. Make sure the right dataset is active (left rail).
    3. 
                    
  3. 
                      Choose the 
                      response (Y)
                       and 
                      predictors (X)
                       using the dropdown chip selectors.
                    
    4. 
                    
  4. 
                      Click 
                      Run
                      . A 
                      “Running… m:ss”
                       indicator shows elapsed time while it computes (nothing runs until you click).
                    
    5. 
                    
  5. 
                      Read the results: tables, plots (hover a plot to download a PNG), metrics
                      (RMSE / R² / accuracy where relevant), and a plain-English interpretation.
                    
    6. 
                  

                  

                    Available families include 
                    Statistical models
                     (linear regression, ANOVA, mixed-effects, logistic, discriminant analysis, PCA, tests), 
                    Machine learning
                     (random forest, SVM, neural net, decision tree, XGBoost,
                    classification, clustering), and 
                    Spatial & LiDAR
                     (point clouds, CHM & tree detection, raster, terrain, hydrology), plus time-series,
                    survival, SEM, Bayesian and GAM screens.
                  

                  

                    Note: a few compute-heavy methods are still being enabled in the browser build and may show a
                    message on their screen. They are being brought online iteratively.
                  

                

                

                  
6. The AI Co-Pilot

                  

                    Open the 
                    Co-Pilot
                     from the top bar. You can ask about the current screen,
                    ask it to 
                    run an analysis for you
                    , or ask it to 
                    explain a plot or result
                    .
                  

                  
    
                    
  • 
                      Grounded, no hallucination
                       — it uses only your data, the screen context,
                      and the tool's own methods. It will not invent numbers or column names.
                    
    •
